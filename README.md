
**Alien Invasion Game**

Alien Invasion is a beginner-friendly Python game based on the project from Python Crash Course, 3rd Edition by Eric Matthes. In this game, we control a spaceship that fires at waves of incoming aliens. The goal is to clear each wave before the aliens reach the ship or breach the screen.

This project helps me practice core programming skills like working with classes, handling user input, updating game objects, detecting collisions, and managing game loops using the Pygame library. I will continue developing and improving the game and this file as I progress through the milestones.

**Track Decision — Track 1: Custom Game Mechanics**

I've chosen Track 1 for this project. Given the time I have available, Track 1 lets me focus milestone one entirely on the ship/bullet mechanics without needing to source custom image assets yet, so I can get a solid foundation in place quickly and expand from there.

**Note**: These plans are part of the milestone nudge assignment and may evolve as development continues.

**Milestone 1 — New Ship Orientation & Movement**

Plan: Use free, properly licensed CC0 assets to maintain a consistent visual style.
Milestone 1 — New Ship Orientation & Movement

Plan:
Ship position: moved to the top of the screen, instead of the bottom.
Movement: the ship will move left and right along the top edge (using the A/D or left/right arrow keys), rather than the original left/right-at-the-bottom setup.
Laser direction: bullets will fire downward from the ship, since the ship is now above the play area instead of below it.
Every module, class, and function will include a complete docstring, per the project requirements.

**Milestone 2 — Custom Alien Sprite and Fleet Orientation**
Not required yet, but planning ahead: since the ship is now at the top firing downward, the alien fleet will need to be inverted so the aliens' "front" (bottom) faces up toward the ship, and the fleet's movement/collision logic will need to match this flipped layout. This will be addressed in Milestone 2.
