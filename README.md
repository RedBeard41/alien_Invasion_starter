
# Neon Space Shooter - Track 2

## Project Description
Neon Space Shooter is a 2D space game created using Python and Pygame. This project builds upon the Alien Invasion tutorial with a custom space theme, updated graphics, and sound effects.

## Milestone 1: Core Player Assets & Theme
For Milestone 1, I customized the following:

- **Spaceship:** Replaced the original ship with a blue-and-red spaceship.
- **Background:** Added a blue-and-purple galaxy background.
- **Lasers:** Replaced the default bullets with red laser graphics.
- **Sound:** Added a laser firing sound effect.
- **Game Title:** Changed the window caption to "Neon Space Shooter - Track 2".

The alien fleet, scoring system, and Play button are temporarily disabled for this milestone.

## Controls
- Left Arrow: Move left
- Right Arrow: Move right
- Space: Fire lasers
- Q: Quit the game

## How to Run
1. Install the dependencies using `pip install -r requirements.txt`.
2. Run `python alien_invasion.py`.
